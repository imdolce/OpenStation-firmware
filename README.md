# "OpenStation" project - Open source firmware for "Trạm hàn v4" (Soldering station v4)

OpenStation is an alternative open source firmware for the "Trạm hàn v4"  (Soldering station v4) - phần cứng mạch bởi **toanthodien16**. This guide describes the **current source: version 0.1.0, Build 14**. 

Special thanks to the AxxSolder project (https://github.com/AxxAxx/AxxSolder) for inspiring the UI design and control logic.

Only the C245 series are tested on this firmware. 

Start with the [user guide](docs/USER_GUIDE.md) to operate the station. The [technical reference](docs/TECHNICAL_REFERENCE.md) explains the firmware, and the [hardware guide](docs/HARDWARE.md) records the implemented pin map and electrical assumptions.

## Hardware and tools

- "Trạm hàn v4" PCB with **CH32X033F8P6**, ST7735 **128 × 160** LCD, encoder/button, compatible iron handle and cartridge, and a suitable DC supply.
- A **WCH-LinkE or compatible WCH-Link** connected to the board's debug/programming interface.
- [PlatformIO Core](https://docs.platformio.org/en/latest/core/installation/index.html) or PlatformIO IDE, with the project platform/framework packages installed by PlatformIO on the first build. The project uses the `ch32v` platform, `genericCH32X033F8P6` board, and `noneos-sdk` framework.
- Windows is the currently used host; the post-upload script also selects a non-Windows `wlink` executable when applicable.

Select the correct tip family/profile and supply before enabling heat. The factory values are not a substitute for electrical and temperature calibration; see the [hardware guide](docs/HARDWARE.md#configured-values-versus-verified-measurements).

## File structure

| Path | Purpose |
| --- | --- |
| [`src/main.c`](src/main.c) | Startup and cooperative event loop |
| [`src/board.c`](src/board.c) | GPIO, backlight, buzzer, millisecond tick, watchdog |
| [`src/power.c`](src/power.c) | TIM1 heater pulse and quiet-window timing |
| [`src/measure.c`](src/measure.c) | ADC acquisition and conversions |
| [`src/control.c`](src/control.c) | Temperature controller, states, sleep behavior |
| [`src/safety.c`](src/safety.c) | Fault detection and heater shutdown |
| [`src/profiles.c`](src/profiles.c) | Factory and custom tip profiles |
| [`src/settings.c`](src/settings.c) | Persistent settings |
| [`src/ui.c`](src/ui.c) | LCD screens and menus |
| [`src/st7735.c`](src/st7735.c) | ST7735 controller driver and display offsets |
