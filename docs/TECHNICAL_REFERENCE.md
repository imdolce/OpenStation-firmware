# OpenStation technical reference

This is a source-based reference for **0.1.0 Build 16d**. [`src/`](../src/) and [`include/`](../include/) are authoritative for present behavior. The files under [`scrap/`](../scrap/) include historical samples and plans; their descriptions are not necessarily implemented now. The [firmware datasheet](FIRMWARE_DATASHEET.md) is a compact behavior summary; the historical MCU document in `scrap/` describes silicon, not these firmware features.

## Startup and execution

[`main.c`](../src/main.c) calls `board_safe_boot()` before LCD setup so **PB7 is low and the heater is off**. It initializes the ST7735, clears controller RAM, then initializes board inputs, TIM1 power timing, stored settings, ADC measurement, safety, control, and UI. It renders the screen, plays a boot sound, and starts the watchdog. New or factory-reset settings enter Welcome with PB7 off; normal heating is gated on a verified saved setup-completion flag. Failure to initialize the LCD leaves the code holding the heater off.

The main loop processes ADC results and input events, runs control when a new quiet-window temperature sample arrives, supervises safety on heater-cycle events, refreshes the display every **100 ms**, and feeds the watchdog. Interrupts handle timing-critical heater switching, ADC progression, the millisecond tick, and buzzer timing. UI fields use partial redraw/caching where practical.

## Heater timing and ADC quiet window

[`app_config.h`](../include/app_config.h) sets a **100 kHz** TIM1 timebase and **5000 ticks** per heater cycle: **50 ms / 20 Hz**. The configured pulse is limited to **4400 ticks / 44 ms**, leaving at least **6 ms off** each cycle. PB7 **high** turns the high-side P-channel MOSFET stage on through its NPN gate driver; PB7 low turns it off. The code starts a pulse at the TIM1 update event, samples PA6 current near **tick 100 (1 ms)** during an active pulse, turns the heater off at a compare event, and schedules the quiet ADC trigger **500 ticks (5 ms)** after the pulse ends. These are firmware timings, not oscilloscope-verified switch or op-amp settling times.

The quiet sequence samples PA1 tip temperature only while the heater is commanded off. It discards the first conversion after switching ADC channels, takes **19 temperature conversions**, drops the highest and lowest, and averages the remaining 17. It then samples PA0 voltage and PA6 off-current, also discarding initial channel-switch conversions. Temperature and voltage pass through a three-cycle median filter. If the heater is still on, or the quiet sample is missing/stale, a new heat command cannot use it. The control loop runs on each accepted quiet sample, nominally **20 times per second**. The TIM1 schedule, rather than display refresh, determines this rate.

## Measurements and control math

- **Supply voltage:** PA0 raw ADC → `raw × 3300 mV / 4095` at the pin → multiply by configured divider ratio **16.3**. This ratio is a source setting and needs board calibration.
- **Temperature:** PA1 ADC voltage is converted to microvolts using a 3.3 V, 12-bit model and 64-bit intermediate arithmetic. The code divides by the selected profile's `temp_uv_per_c`, adds its internal calibration intercept and the shared manual room-reference change since that profile's calibration, then applies the stored six-anchor correction curve. The six anchors are 100, 200, 300, 350, 400, and 450 °C. No independent cold-junction sensor is read. Profiles → Room Temp is a manually entered 0–50 °C approximation shared by all profiles; Tip Setup records its room entry on successful save. Changing the actual reference-junction temperature without updating this setting can shift readings. An ADC value **≥3900** marks the tip open; **≤3800** restores presence, giving hysteresis. Temperature scale and six-point factory data are provisional, not certified accuracy.
- **Current:** PA6 is read during an on pulse; the zero-current baseline is calibrated while off. The ADC delta is converted with configured **340 µV/mA** at the ADC input. This is an empirical firmware scale, not a verified amplifier/shunt specification. An off-pulse PA6 sample separately checks for unexpected current.
- **Displayed average current:** `I_on × actual_on_ticks / 5000`. **Displayed power:** `VIN × I_average`; the code converts mV × mA into mW. These are estimated electrical averages from one on-pulse sample and commanded pulse duration, not direct continuous integration or a calorimetric heater-power measurement.
- **Duty limiting:** the requested PID duty is bounded by the active profile's maximum duty, configured maximum power and nominal resistance (`P_max × R_nom / VIN²`), rated-voltage rule (`V_rated² / VIN²`), the 44 ms pulse cap, and validity/fault gates. Factory `max_power_mw` values are **150000** for C210/TX1/TX2/T12/GOOT, **200000** for C245/APOLLO, and **400000** for C115/C470. The editable value and runtime limiter are both capped at **800000 mW (800 W)**; these are configured ceilings, not demonstrated safe continuous output. The other bounds may reduce effective duty.

The active profile contains Q8 PID constants. The controller computes proportional error, integrates with anti-windup, applies derivative to the measured temperature, clamps the request to 0–1000 permille, and limits an upward change to 100 permille per sample. Build 16d's factory C245 constants are **Kp 8, Ki 2, Kd 0.5** in Q8 notation. Control uses the *selected* profile; `TIP_IDENTIFY` is only a short settling state and performs **no automatic resistance identification**.

## States and protection

The state machine declares `BOOT_SAFE`, `NO_TIP`, `TIP_IDENTIFY`, `IDLE`, `HEAT_UP`, `REGULATE`, `BOOST`, `SLEEP`, `COOLING`, and `FAULT_LATCHED`. A click in IDLE with a present tip, valid quiet sample and valid supply starts heating. `HEAT_UP` becomes `REGULATE` within 5 °C of setpoint. A double-click while heating starts boost only when its configured increment is nonzero. Boost adds **0–100 °C** (5 °C menu steps) to the base setpoint, bounded by station and tip limits, for a configured **15–120 s** (5 s steps); defaults are **+50 °C for 30 s**. A further double-click adds that duration to the *remaining* boost time, saturated at **5999 s (99:59)** to fit the two-digit-minute display. It does not compound the temperature increment. A single click shuts the heater off; encoder rotation changes the base setpoint and exits Boost. The status box stays yellow with black **Boost** and `MM:SS`, while the Set readout shows the effective boosted target in red and a red parenthetical actual increment such as `(+60°C)`. Profile changes force heat off. Stand low begins a 0–30 s delay; VIB low after arming causes immediate sleep; sleep time is 30–1800 s and then turns heating off. See the [user guide](USER_GUIDE.md#sleep-and-wake) for screen behavior.

Active checks in [`safety.c`](../src/safety.c) include: missing/stale quiet ADC data (**200 ms** threshold after first sample), tip open/very low PA1 raw, selected-family supply range, measured temperature more than **15 °C** above the profile limit or above **515 °C**, off-current above **500 mA** for two samples, and a temperature drop over **100 °C within 300 ms** while heating. TIM1 also has a pulse-timeout shutdown. Faults latch PB7 off and capture a snapshot. The Sensor Drop fault needs reset and inspection. `Ignore Faults` bypasses most supervisor checks, but **ADC Stale and Pulse Time remain enforced**. `FAULT_OVERCURRENT` and `FAULT_NO_CURRENT` exist as enum names, but Build 16d does not implement an instantaneous current ceiling or a normal no-current trip.

Build 16d has `STATION_HEATER_OUTPUT_ENABLE=1` and `STATION_SERVICE_ALLOW_UNCHARACTERIZED=1`. Factory profiles have `characterized=0`; the latter setting permits them to heat for development. Completing single-point Tip Setup sets `characterized=1` for that profile. Neither the 800 W hard software ceiling nor enabled heating validates the MOSFET, supply, wiring, or cartridge limits.

## Persistent flash

The [`linker script`](../scrap/linker.ld) allocates **52 KiB** from `0x08000000` for application code and leaves the upper flash region for data. [`profiles.c`](../src/profiles.c) uses nine 1 KiB pages from **`0x0800D000`** for the nine tip families, each with ten 96-byte custom-profile slots and a checksum. [`settings.c`](../src/settings.c) stores a checksummed, versioned record in the 1 KiB page at **`0x0800F400`**. It reads valid saved values at startup; compiled defaults are used when there is no valid record. The current settings format is **version 12 (620 bytes)**, including setup completion. A previously reserved byte stores the shared room reference as `room+1` (1–51); zero in an older version-12 record maps to the 30 °C default without changing its flash layout. Valid Build 14/version 9 and version 11 records migrate in memory. Version 11 retains its completion flag; version 9 is treated as already configured. Selected custom profiles and existing profile slopes remain in use. Earlier supported formats still have migration paths. Saving writes version 12. `Save to Flash` writes current settings, and Factory Reset restores defaults, erases custom profiles, and saves the reset settings. A full-chip erase or a different linker layout can remove stored profiles/settings.

## Build 16d Tip Setup

The UI is landscape only (160 × 128); Display offers normal or 180° rotation. Portrait values from saved records map to normal landscape. Factory profile slopes, stored as ADC-side microvolts per degree, use nominal 126× pre-amplifier estimates: C115/C210 1197, C245/C470 5040, T12/TX1/TX2 2646, GOOT/APOLLO 5166 µV/°C. These are provisional starting points. Valid saved slopes and six-point values are retained during migration. The sensitivity editor displays `temp_uv_per_c / 126` in 0.1 µV/°C steps without rewriting on display.

[`tip_setup.c`](../src/tip_setup.c) stages the profile in RAM while it records a heater-off ADC baseline at the manually entered room temperature (0–50 °C, default 30 °C). Revision-3 profiles reconstruct their saved room ADC from the profile's original calibration room for hot retries, even when the shared room setting has changed. Rotating the optional sensitivity entry supplies a nominal pre-amplifier value in 0.1 µV/°C steps; clicking then skips heating, shows a profile-specific reminder, and saves the manually supplied slope and room offset after another click. That path resets corrections to neutral anchors and marks the profile uncharacterized, because the value was not thermometer-checked. Clicking without rotating enters the single estimated 200 °C heater stage, limited to 600 s, 30 W estimated power, and 20% duty. Its capture uses a fresh quiet-window ADC sample and the entered external thermometer value. Tip presence, ADC freshness, supply, stand, armed tilt, fault latch, and TIM1 pulse timeout remain checked.

The result menu highlights only its selected action and labels the default save **Save Profile (Default)**. The old “Room + hot capture” result line and Tip Setup heating progress bar are absent. The main screen appends **Default** to factory profile names; custom profiles keep their saved names. The preparation page has no bottom progress strip. The one-point calculation uses `(V_hot − V_room) / (T_external − T_room)` for ADC-side sensitivity in µV/°C. It rejects non-rising ADC/thermometer readings, a slope outside **1008–11970 µV/°C** (8–95 µV/°C before nominal 126× gain), or a room offset outside **−100 to +100 °C**. A successful checked save stores the profile slope, internal intercept, and calibration room, copies the entered room into the shared manual setting, marks the profile characterized, and resets the six correction anchors to neutral values. The room entry approximates the reference-junction temperature and is not measured cold-junction compensation. One hot reading does not validate the full operating range.

The separate Cal Wizard measures external readings at base-temperature targets **200, 300, and 400 °C** with the existing stable-reading gate. It requires station and tip maxima that permit the profile's mapped 400 °C calibration target. The six-anchor profile and version-12 settings layout are unchanged. Only the 200, 300, and 400 °C points appear in **3-Point Values**; editing one re-derives the hidden anchors. Internally: 100 and 450 °C hold the nearest measured correction, while 350 °C is interpolated between the measured 300 and 400 °C values. The wizard constrains entered values so the derived curve remains monotonic and within 0–550 °C. Factory-default setup still requires two Yes confirmations, initially No. Completion is persisted only after verified flash save; cancelled or failed first-time setup leaves heating disabled. No physical cartridge auto-identification is implemented.

[Texas Instruments' thermocouple measurement guide](https://www.ti.com/lit/an/sbaa274a/sbaa274a.pdf) explains why a measured reference-junction temperature is needed for accurate compensation; this board uses a manual approximation instead.
