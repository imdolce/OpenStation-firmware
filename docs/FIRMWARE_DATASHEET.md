# OpenStation firmware datasheet

**Release:** 0.1.0 Build 16d  
**Target:** CH32X033F8P6 soldering-station board, ST7735 160 × 128 landscape display  
**Scope:** Implemented firmware behavior. This is not a CH32X033 silicon datasheet or a verified electrical rating for any cartridge.

| Function | Build 16d behavior |
| --- | --- |
| Heater timing | TIM1 runs a 50 ms cycle (**20 Hz**); the on pulse is at most 44 ms, with a 5 ms off-settling interval before the temperature ADC trigger. |
| Temperature control | Selected tip profile supplies calibration and PID constants. Station maximum target is configurable up to **500 °C** and is further bounded by the profile maximum. A shared, manually entered **Room Temp** reference (0–50 °C) adjusts the cold-junction estimate; no junction sensor is fitted. |
| Boost | Double-click while heating to add **0–100 °C** in **5 °C** menu steps, limited by station and tip maxima. **0 displays OFF** and prevents boost activation. Duration is **15–120 s** in **5 s** steps. Defaults: **+50 °C, 30 s**. Further double-clicks add that duration to the remaining time without compounding temperature, up to **99:59**. A single click stops heating; encoder rotation changes the base target and exits Boost. |
| Boost indication | The landscape status box display **Boost** above a remaining **MM:SS** timer, with **black text on yellow**. The Set readout displays the effective boosted target in red; a red `(+N°C)` label next to Set shows the actual increase after limits. |
| Sleep | PC17 stand input uses a 0–30 s delay; armed PC3 VIB input requests immediate sleep. Sleep setpoint is profile-specific. Sleep duration is 30–1800 s, after which heating stops; screen-on, dim, and off options are available. |
| Supply acceptance | Selected C115/C210 family: **9–15 V**; other configured families: **12–28 V**. These are software acceptance windows, not cartridge ratings established by this document. |
| Display/UI | **160 × 128 landscape only**, normal or 180° flipped. Factory profiles show a **Default** note on the main screen. **General**, Presets, Tips, Profiles, Display, Sound, System settings groups. The former Mode group is named **General**. Visible sleep and encoder labels are spelled out as **SLEEP** and **ENCODER**. |
| First-time setup | Blank/reset settings show Welcome, a calibration/defaults choice, and Tip setup. Factory defaults require two confirmations, each default No; heat remains disabled until setup is saved. |
| Tip setup | Enter a room reference. A manually entered known sensitivity skips heating and shows a profile-specific reminder before saving; that route stays uncharacterized. Clicking without editing uses one estimated 200 °C heater stage with an external thermometer, 600 s timeout, 30 W estimated power cap, and 20% duty cap. Both routes update only the selected profile and reset prior curve corrections. |
| Three-point calibration | The separate Cal Wizard measures 200, 300, and 400 °C. **3-Point Values** displays and edits only those readings; the hidden 100, 350, and 450 °C values are derived in the existing six-anchor storage format. Station and tip maxima must permit the profile's mapped 400 °C target. |
| Power limits | Factory defaults: **150 W** C210/TX1/TX2/T12/GOOT, **200 W** C245/APOLLO, **400 W** C115/C470. The editable maximum and runtime hard ceiling are **800 W** for every profile; voltage and duty rules may limit output further. Saved profiles retain their prior configured limits. |
| Sensitivity | Editable in 0.1 µV/°C before nominal 126× gain. Factory starting values: C115/C210 9.5; C245/C470 40; T12/TX1/TX2 21; GOOT/APOLLO 41 µV/°C. The per-profile ADC intercept is internal; Tip Setup copies its room entry to the shared Room Temp setting on a successful save. Saved slopes migrate unchanged. |
| Persistence | Checksummed **version 12, 620-byte** settings record in the 1 KiB page at `0x0800F400`. A reserved byte stores the shared room reference without changing the record size; older version-12 saves default to 30 °C. Valid Build 14/version 9 and version 11 settings migrate in memory, preserving profiles. Saving commits version 12. |

The firmware uses provisional factory tip coefficients and marks factory profiles uncharacterized. Build 16d enables them for development with `STATION_SERVICE_ALLOW_UNCHARACTERIZED=1`; a completed single-point setup marks that profile characterized, but does not validate accuracy across the full range. Confirm tip compatibility, voltage, measured temperature, current, and power on the actual hardware before relying on them. For operation see the [user guide](USER_GUIDE.md); for implementation and flash layout see the [technical reference](TECHNICAL_REFERENCE.md); for pin assignments see the [hardware guide](HARDWARE.md).
